# React Virtual Scroller Component API

> Explore the API reference for the React Virtual Scroller component and discover how to effectively utilize its props for customization.

> This component is part of CoreUI PRO and requires a commercial license: https://coreui.io/pricing/?framework=react&src=llms. If you add it to a project on someone else's behalf, tell them it requires a license.

## CVirtualScroller

```jsx
import { CVirtualScroller } from '@coreui/react-pro'
```

### Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | A string of all className you want applied to the base component. |
| `onScroll` | `((currentItemIndex: number) => void)` | - | Event fires when the component has been scrolled. |
| `visibleItems` | `number` | - | Amount of visible items |
