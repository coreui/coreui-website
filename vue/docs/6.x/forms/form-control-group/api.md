# Vue Form Control Group Component API

> Explore the API reference for the Vue Form Control Group components and discover how to effectively utilize their props for customization.

## CFormControlGroup

```jsx
import { CFormControlGroup } from '@coreui/vue'
```

### Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `string` | `undefined` | Size the frame small or large - every part inside follows it. |
