# Vue Form Floating Labels Component API

> Explore the API reference for the Vue Form Floating Labels component and discover how to effectively utilize its props for customization.

## CFormFloating

```jsx
import { CFormFloating } from '@coreui/vue'
```

### Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `always` | `boolean` | - | Keeps the label floated and the placeholder visible while the field is empty. |
