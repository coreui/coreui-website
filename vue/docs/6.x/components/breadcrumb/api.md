# Vue Breadcrumb Component API

> Explore the API reference for the Vue Breadcrumb component and discover how to effectively utilize its props for customization.

## CBreadcrumb

```jsx
import { CBreadcrumb } from '@coreui/vue'
```

## CBreadcrumbDivider

```jsx
import { CBreadcrumbDivider } from '@coreui/vue'
```

## CBreadcrumbItem

```jsx
import { CBreadcrumbItem } from '@coreui/vue'
```

### Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `active` | `boolean` | - | Toggle the active state for the component. |
| `as` | `string` | `'a'` | Component used for the inner link node. Either a string to use a HTML element or a component. |
| `href` | `string` | - | The `href` attribute for the inner link component. |
