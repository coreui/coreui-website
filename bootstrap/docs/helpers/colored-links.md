# Bootstrap 5 Colored Links

> Colored links with hover states

You can use the `.link-*` classes to colorize links. Unlike the [`.text-*` classes](https://coreui.io/bootstrap/docs/utilities/colors/), these classes have a `:hover` and `:focus` state.

> Some of the link styles use a relatively light foreground color, and should only be used on a dark background in order to have sufficient contrast.
