Compliance

MarkdownChatGPTClaude

The WCAG 2.2 success criteria each CoreUI for Bootstrap component is tested against, whether the component meets them on its own, and how they are checked.

On this page
  • Statuses
  • Summary
  • Components

Each component below is tested against the WCAG 2.2 success criteria that apply to it. The list comes from the configuration of our automated conformance suite, which runs on every change: it renders the component’s documented examples in Chromium, checks the criteria with axe-core where a rule exists, and some of the others with scripted keyboard and focus steps. A criterion the component meets fully or in part fails the build when it regresses, where axe-core or a scripted step checks it; the others are reviewed by hand.

Conformance is a property of a whole page. A component that meets a criterion keeps meeting it only with the markup and texts its documentation asks for, and criteria marked as your responsibility depend on how you use the component. See the overview for what the components take care of and what stays with your markup.

Statuses

StatusMeaning
Built inHandled by the component out of the box.
Partially handledThe component helps, but you must finish the job.
Your responsibilityYour app must satisfy this — the component can’t enforce it.

Accordion

Accordion documentation

CriterionLevelStatusNotes
2.1.1 KeyboardABuilt inEach header is a native summary element, so Enter and Space toggle its panel and Tab reaches every header. Arrow, Home and End keys do not move between headers.
4.1.2 Name, Role, ValueAPartially handledThe browser exposes each header and its expanded state from the native details and summary elements. Known gap: the header is not exposed as a button with aria-controls, and the panel is not a labelled region.
1.3.1 Info and RelationshipsAPartially handledA bare summary element is not a heading. Wrap the label in an h2–h6 inside the summary, as the examples do, so the sections stay reachable by heading navigation.
2.4.7 Focus VisibleAABuilt inThe header draws a focus ring on :focus-visible, so keyboard focus is visible while a mouse click leaves it alone.
1.4.3 Contrast (Minimum)AABuilt inHeader text meets the contrast minimum in both the closed and the open state.

Autocomplete documentation

CriterionLevelStatusNotes

Calendar

Calendar documentation

CriterionLevelStatusNotes
4.1.2 Name, Role, ValueABuilt inThe calendar is a role=grid of role=gridcell cells, so a day, month, quarter or year can be marked selected. Each day cell carries an aria-label with its full date unless a custom renderDayCell is used, month, quarter and year cells are named by their text, today's cell carries aria-current="date", and a week row carries aria-selected when whole weeks are selectable.
